# Immersive Worlds

Approved in chat: immersive interactive scenes with a fourth experimental Ripple Field.

Ocean Calm uses a layered shoreline, a breathing halo and waves driven by the same clock. Inhale four seconds, exhale six seconds, no required hold. Users can pause or choose still visuals.

Soft Focus uses a warm light in a quiet dusk scene. Choose a steady light or a slow drift; drifting stops when paused and is disabled with reduced motion.

Grounding Garden uses an illustrated botanical scene and one sense prompt at a time. Notice or skip each prompt, go back, restart or leave. Skipped senses are not counted as noticed. No performance score.

Ripple Field is visibly experimental. Tap the field or press its keyboard button to place a ripple. Limit visible ripples to eight; no microphone, audio, network, tracking or persistence. Clear, pause and reset remove or stop motion. Completion disables new interactions until restart.

All experiences retain the existing accessible dialog and bounded session clock. Motion preference defaults to the system setting and can be reduced by the user. English and Spanish are explicit languages, not proxies for culture. Sense prompts can be skipped without explanation. No personal context is required or retained.

Visual language: system typography, large open scenes, ink/dusk blue, sea glass, muted sage, amber light, high-contrast restrained controls. Locally authored SVG and CSS avoid WebGL dependencies. Existing DESIGN_SYSTEM.md is the visual reference. Checked recent.design and React Bits; Motion Primitives site was unavailable. Their animation dependencies are unnecessary for these simple bounded effects.
