# Living Light

Approved direction: an immersive field of luminous threads. Sweep to guide currents, hold to gather a bloom, release to unfurl. Two pointers adjust spread/rotation. Keyboard arrows position the field, a toggle gathers/releases, and separate spread/rotation controls provide equivalent access. Optional locally synthesized tones follow the formation, never initialized without requesting sound. No scores, saves, tracking or external requests.

Art: fully authored procedural Canvas, navy #081421, pearl cyan #99dacc, muted violet #b0a0dc and restrained amber #e6c498. No raster image or new dependency is needed. React Bits Iridescence was reviewed in the preceding World work as a reference for direct material response; this uses custom geometry rather than importing its OGL runtime. Guides sit below a generous interaction surface.

Bound 96 threads × 64 segments, 1.2 million pixels and 30fps. Stop continuous rendering before Start, paused/hidden/complete and still. Still mode uses immediate deliberate geometry changes without passive motion. Pause cancels held gestures; reset clears formation and optional sound. Static SVG fallback preserves keyboard shaping. English/Spanish copy and visible focus, 320px/landscape layout verification. Context/culture: an abstract material rather than an inferred culturally calming place; no personal inputs are needed. Privacy: ephemeral pointers and preferences only.

Sequence: failing catalog and gesture tests; typed allowlist/seed; Canvas renderer and accessible gesture surface; optional three-voice audio lifecycle; procedural preview; unit/type/build and browser input/still/fallback/lifecycle tests; desktop/mobile visual review; independent review; PR/CI/release under standing authorization.
