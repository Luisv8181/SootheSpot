# Quiet Rain

Add a sixth sensory World: a sheltered rainy window overlooking a misty valley. Original local generated artwork establishes depth; custom Canvas 2D adds bounded refracting droplets and condensation that responds to touch. References: Codrops Rain & Water Effect Experiments (refraction/trails), React Bits Iridescence (material response). Recent.design was checked; its showcase does not supply this interaction. Motion Primitives returned HTTP 403; no new runtime dependency is needed.

Palette: midnight #10252b, mist #8ca5a4, ivory #fff4dc, amber #ddb47a. System type, bilingual controls below the scene. No guide overlaps the glass. Generous scene height at 320px and landscape; scrolling preserves controls.

Drag to clear glass; arrows position a keyboard cursor and Enter/Space clear an area. Fog returns slowly only during an active session. No goal, score or required breathing. Optional locally synthesized rain starts off, with volume/stop. Audio suspends on pause/hidden and is disposed on off/reset/completion/exit. Initialization requires a user gesture.

Privacy/context/culture: no microphone, camera, account context, network audio, saved gestures, or inferred culture. English/Spanish copy. Fictional shelter, not a prescribed universally calming place. Users can immediately leave or choose another World.

Order: failing catalog/bounds tests; allowlisted glass activity/seed; artwork/review/provenance; native renderer/audio; preview/layout; browser input/lifecycle/localization/static/fallback/privacy/completion tests; screenshot inspection; unit/type/build/full browser suite; independent review; PR/CI/publication under existing authorization.

Budgets: 96 droplets, 120 clear marks, 1.5 million physical canvas pixels, 30fps, two local image variants and one two-second audio buffer. No continuous work before Start, paused/hidden/complete or still. Canvas failure keeps the artwork and explains clearing is unavailable. Image failure keeps an authored gradient fallback.
