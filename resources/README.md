# SootheSpot Resource Library

This directory contains metadata for external resources that can be discovered through SootheSpot.

These are references, not copies.

Users should normally be sent to the original publisher website or app store listing. Do not copy third-party content into this repository unless the project has permission.

## Structure
- resources.json: machine-readable registry
- schema.json: resource record schema
- categories.md: controlled vocabulary and tagging guidance

## Resource record philosophy
A resource record answers:
1. What is it?
2. Who made it?
3. What does it help with?
4. Who is it intended for?
5. How can someone access it?
6. What evidence or authority supports its description?
7. Has SootheSpot reviewed it?
8. When was it last checked?

Keep descriptions short and factual.

## Adding a resource
1. Find the official publisher page.
2. Prefer primary sources over aggregators.
3. Record the official URL.
4. Record platform and cost.
5. Record intended population and independent-use limitations.
6. Record evidence/source notes when available.
7. Add last_verified_at.
8. Do not reproduce copyrighted content.

The registry should include both established clinical apps and small useful digital experiences: breathing timers, grounding exercises, interactive visualizations, journaling tools, sensory tools, sleep resources, multilingual resources, accessibility tools, and clinician-created resources.
