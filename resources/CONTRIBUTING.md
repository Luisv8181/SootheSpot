# Contributing to the Resource Registry

The registry is a directory, not a content scraper.

## Add a resource

1. Start with the publisher's official website or primary documentation.
2. Add a candidate record to the review queue or directly to resources/resources.json only when the required checks are complete.
3. Record what the publisher actually says. Do not turn popularity, marketing language, or an app-store rating into a clinical claim.
4. Record limitations and whether professional guidance is recommended.
5. Keep external content external unless licensing explicitly allows reuse.
6. Set the review status honestly.

## Review states

- unreviewed: discovered, not screened
- screened: basic publisher, purpose, link, and scope checks completed
- clinically_reviewed: reviewed by a qualified clinical reviewer
- verified: primary-source metadata and relevant claims checked
- deprecated: no longer available, maintained, or appropriate

## Safety resources

Safety-plan and crisis resources must remain clearly separated from ordinary coping tools. Do not recommend a crisis resource as a generic wellness activity.

## No universal rankings

Do not add "best", "top", or numerical efficacy scores. Use transparent metadata and filters instead.

## Pull request checklist

- [ ] Official/primary source used
- [ ] URL works
- [ ] Publisher confirmed
- [ ] Description is factual and concise
- [ ] Intended population recorded
- [ ] Independent-use scope recorded
- [ ] Limitations recorded
- [ ] Review status is justified
- [ ] Verification date recorded
- [ ] No copied third-party content
- [ ] Resource is placed in the correct category
